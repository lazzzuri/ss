# Окна: проверка спроса и лендинг

Оконщики загружены на недели вперёд (Bliss: «розписано на три тижні»). Выясняем, на чём зарабатывать:
**А. продавать им время** («диспетчер» заявок) или **Б. продавать им готовые заявки** (посредник).

## Порядок

1. **[1-proverka.md](1-proverka.md)**: проверка рассылкой (5–13 ноября). Где взять 300–500 оконщиков в 3–5 городах, как рассылать волнами без спама, готовые письма, скрипт звонка, правила решения по каждому городу.
   Ответы записывать в **[1-proverka-tablica.csv](1-proverka-tablica.csv)** (открыть в Google Sheets).
2. **[2-landing-i-reklama.md](2-landing-i-reklama.md)**: только для городов, где 2+ компании готовы платить за заявки. Лендинг, тексты рекламы, бюджет 1–2 тыс. грн, расчёт цены заявки.

## Лендинг

- `landing/index.html`: рабочая страница для хостинга (Netlify, форма уже размечена). Перед запуском поменять блок `CONFIG` в начале скрипта: название, город, контакты, цены и `demo: false`.
- `landing/zayavka.html`: та же страница без обёртки, из неё сделана демо-ссылка.
- Демо (закрытая ссылка, открыть может только владелец; делиться через меню Share): https://claude.ai/artifact/ELRonLrNaNxo2nuL85iR7V

Одна страница работает для обеих моделей:
- **Модель Б:** твой лендинг для рекламы, заявки приходят тебе.
- **Модель А:** показать оконщику как «вот так клиенты будут оставлять вам заявки с размерами и ценой, без звонков». После «Надіслати заявку» видно, какой текст получит мастер.
